# Schritt für Schritt

1. **Die Seite gliedern.** Überschriften dort setzen, wo ein Abschnitt beginnt,
   und für gleichrangige Abschnitte dieselbe Ebene verwenden. Das Widget kann nur
   zeigen, was schon da ist.
2. **Den Block einfügen.** Im Editor „Ankernavigation" wählen — am besten in eine
   schmale Spalte neben dem Text oder über den ersten Abschnitt.
3. **Die Ebene wählen.** Die Ebene der Abschnitte, nicht die des Seitentitels. Ist
   der Seitentitel ein H1 und die Abschnitte sind H2, dann **H2**.
4. **Den Titel eintragen** — oder leer lassen. Leer heißt: nur die Liste, keine
   Überschrift darüber.
5. **In der Vorschau prüfen.** Die Liste erscheint sofort und richtig; was im
   Editor steht, steht auch auf der Seite.

## Beim Ändern der Seite

Die Liste folgt dem Text, während daran gearbeitet wird: eine neue Überschrift
taucht auf, eine gelöschte verschwindet. Nichts anzuklicken, nichts zu
aktualisieren.

## Auf dem Telefon

Dort ist die Liste eingeklappt und zeigt nur den Titel mit einem Pfeil. Ein Tipp
klappt sie auf. Auf dem Bildschirm ab 768 Pixel Breite steht sie immer offen.
