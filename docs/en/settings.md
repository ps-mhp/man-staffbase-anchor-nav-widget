# Settings

## Heading Level

Which level the list displays: **H1** through **H6**. The default is **H2**.

This refers to a specific level, not “from this level onward.” If you select H2, you’ll get the H2
headings on the page—the H3 headings below them will be omitted.

If the widget doesn’t display anything, the page isn’t using that level. In that case, check the text
to see which level the sections actually have.

## Title

The heading above the list, for example, “At a Glance.” Leave it blank
to hide it; the list remains.

The title is translated along with the page. The list entries do not need to be
translated—they are the page’s headings and already carry their translations
anyway.
