# Anchor Navigation

This widget displays a list of links that you maintain yourself. Clicking
a link takes you to the corresponding heading on the page; a red marker indicates
which section you’re currently reading and moves along as you scroll.

The list doesn’t generate automatically. In the **Edit Links** window,
you specify which entries exist, what they’re called, and the order in which they
appear—the quickest way is to select headings and widgets from the page using a
search list. The
widget only searches for sections when someone scrolls or clicks on an entry
— it doesn’t do anything in the background while the page is loading.

## What it’s designed for

Long pages with a clear structure—a car model with its features,
a guideline with its sections. It’s not worth it for short pages.

## What it doesn’t do

- **It doesn’t find headings on its own.** Each entry is created manually.
  If a new section is added to the page, it’s added to the list as well.
- **It doesn’t support nesting.** The list is flat, not a tree.
