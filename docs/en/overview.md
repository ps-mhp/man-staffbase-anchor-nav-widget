# Anchor Navigation

The widget displays a list of links that you maintain yourself. A single click
takes you to the corresponding heading on the page; a red marker indicates
which section you’re currently reading and moves along as you scroll.

The list doesn’t generate automatically. In the settings dialog, you specify which
entries are included, what they’re called, and the order in which they appear. The
widget only searches for the sections when someone scrolls or clicks on an entry
— it doesn’t do anything in the background while the page is loading.

## What it’s for

Long pages with a clear structure—a car model with its features,
a guideline with its sections. It’s not worth it for short pages.

## What it doesn’t do

- **Doesn’t find headings on its own.** Each entry is created manually.
  If a new section is added to the page, it’s included in the list.
- **Doesn’t nest.** The list is flat, not a tree.
