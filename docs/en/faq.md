# FAQ

## The widget isn't displaying anything.

The page doesn't have a heading at the specified level. Select a different level
or add a heading to the text. An empty widget doesn't display anything—
not even an empty box or a title.

## It shows too few headings.

Headings with empty text are ignored. And headings within the
widget itself do not count, otherwise it would reference itself.

## It displays its own title as an entry.

This shouldn’t happen. If it does occur, the heading is outside
the widget container—for example, as a separate text block above it. In that case, either use the
widget’s title or select a level that the text block does not have.

## The red marker doesn’t follow along.

It follows the scrolling and stays with the heading that most recently reached the top
quarter of the window. At the very top of the page, it is positioned at the first
entry. If you have “Reduce Motion” enabled, you’ll see it jump instead of
glide—this is intentional.

## Can the order be changed?

No. The list follows the order in the text. If you want to change the order of the links,
change the order of the sections.

## What if two headings have the same name—does the link jump to the correct one?

Yes. The links remember the heading itself, not its name.
