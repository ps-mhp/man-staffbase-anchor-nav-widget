# Step by Step

1. **Organize the page.** Place headings where a section begins,
   and use the same level for sections of equal importance. The widget can only
   display what’s already there.
2. **Insert the block.** In the editor, select “Anchor Navigation”—preferably in a
   narrow column next to the text or above the first section.
3. **Select the level.** The level of the sections, not that of the page title. If
   the page title is an H1 and the sections are H2, then select **H2**.
4. **Enter the title**—or leave it blank. Blank means: just the list, no
   heading above it.
5. **Check the preview.** The list appears immediately and correctly; what’s in the
   editor is also what appears on the page.

## When editing the page

The list follows the text as you work on it: a new heading
appears, a deleted one disappears. No need to click anything or
refresh the page.

## On a phone

On a phone, the list is collapsed and shows only the title with an arrow. A tap
expands it. On screens 700 pixels wide or wider, it is always open.
