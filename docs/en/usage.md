# Step by Step

1. **Organize the page.** Place headings where each section begins.
   The widget only jumps to headings that exist on the page.
2. **Insert the block.** In the editor, select “Anchor Navigation”—preferably in a
   narrow column next to the text or above the first section.
3. **Create the links.** Save the page once, then open the
   settings dialog—the **Edit Links** window will appear
   automatically. Under **Add Page Element**, search for and select the heading
   or widget for each section. Alternatively, do it manually: **New Link**,
   enter the link text, leave the destination blank, or enter the heading text
   instead.
4. **Enter the title**—on the right under **Navigation**, or leave it blank.
   Blank means: just the list, no heading above it.
5. **Check in the window.** **Desktop**, **Tablet**, and **Mobile** at the top show the
   navigation at device width. Then click **Apply** and save the page.
6. **Check in the page preview.** Click each entry once:
   If it doesn’t jump, the text in the “Link Text” or “Target” field doesn’t exactly match the
   heading.

## When editing the page

The list does not automatically update with the page. If you add or
delete a section, adjust the list accordingly. Links from the selection (block ID) remain valid when
renaming a heading; links via the text do not.

## On a phone

On a phone, the list is collapsed and shows only the title with an arrow. A tap
expands it. On screens 768 pixels wide or wider, it is always open.
