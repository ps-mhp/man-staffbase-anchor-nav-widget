# Step by Step

1. **Organize the page.** Place headings where each section begins.
   The widget will only jump to headings that exist on the page.
2. **Insert the block.** In the editor, select “Anchor Navigation”—preferably in a
   narrow column next to the text or above the first section.
3. **Create the links.** Open the settings dialog—the
   **Edit Links** window appears automatically. For each section, drag the heading
   or the widget from the **Page Layout** on the right into the list, or
   search and select via **New Link**. Even headings that haven’t been saved yet
   are already available for selection. Alternatively, do it manually: **New Link** →
   **Empty Link**, enter the link text, leave the destination blank, or enter the text of the
   heading.
4. **Enter the title**—on the right under **Navigation**, or leave it blank.
   Leaving it blank means: just the list, no heading above it.
5. **Check in the preview window.** **Desktop**, **Tablet**, and **Mobile** at the top show the
   navigation at device width. Then click **Apply** and save the page.
6. **Check in the page preview.** Click each entry once:
   If it doesn’t jump, the text in the link text or destination doesn’t exactly match the
   heading.

## When editing the page

New sections do not automatically appear in the list. If a linked
heading is deleted or renamed, the widget in Studio asks whether the
link should be removed or updated. A link whose destination is missing
will not appear on the page.

## On the phone

There, the list is collapsed and shows only the title with an arrow. A tap
expands it. On screens 768 pixels wide or wider, it is always open.
