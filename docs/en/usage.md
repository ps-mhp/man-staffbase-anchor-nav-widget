# Step by Step

1. **Organize the page.** Place headings where each section begins.
   The widget only jumps to headings that are present on the page.
2. **Insert the block.** In the editor, select “Anchor Navigation”—preferably in a
   narrow column next to the text or above the first section.
3. **Enter the title**—or leave it blank. Leaving it blank means: just the list, no
   heading above it.
4. **Create the links.** Save the page once, then in the **Edit Links
  ** dialog, under **Add Page Element**, select the
   heading or widget for each section. Alternatively, do it manually: **Add Link
  **, enter the link text, leave the destination blank, or enter the text of the
   heading. **Apply**, then save.
5. **Check in the preview.** Click each entry once: If it doesn’t jump,
   the text in the “Link Text” or “Target” field doesn’t exactly match the heading.

## When editing the page

The list does not automatically update with the page. If you add or
delete a section, adjust the list accordingly. Links from the selection (block ID) remain valid when
renaming a heading; links via the text do not.

## On a phone

On a phone, the list is collapsed and shows only the title with an arrow. A tap
expands it. On screens 768 pixels wide or wider, it is always open.
