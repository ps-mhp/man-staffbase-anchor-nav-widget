# Navegação por âncoras

O widget apresenta uma lista de ligações que tu próprio atualizas. Um clique
leva-te diretamente ao título correspondente na página; um marcador vermelho indica qual
foi a última entrada clicada.

A lista não é criada automaticamente. É no painel de configurações que define quais
as entradas existentes, como se chamam e em que ordem aparecem. O
widget só pesquisa a página quando alguém clica numa entrada — durante o
carregamento da página, não realiza nenhuma ação em segundo plano.

## Para que serve

Páginas longas com uma estrutura clara — um modelo de veículo com os seus equipamentos,
uma diretiva com as suas secções. Em páginas curtas, não vale a pena.

## O que não faz

- **Não identifica títulos automaticamente.** Cada entrada é criada manualmente.
  Se for adicionada uma secção à página, esta também deve constar na lista.
- **Não acompanha a rolagem.** O marcador não acompanha a rolagem, mas permanece na
  última entrada clicada.
- **Não aninha.** A lista é plana, não é uma árvore.
