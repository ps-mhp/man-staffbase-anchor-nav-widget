# Navegação por âncoras

O widget lê os títulos da página e apresenta os de um determinado nível — H1 a
H6 — como uma lista de ligações. Um clique leva-nos diretamente para o local correspondente; durante a leitura,
um marcador vermelho desloca-se para o título em que nos encontramos.

A lista é criada ao carregar a página. Não há nada para atualizar: quem
renomear, deslocar ou eliminar um título altera, assim, a navegação.

## Para que serve

Páginas longas com uma estrutura clara — um modelo de automóvel com os seus equipamentos,
uma diretiva com as suas secções. Em páginas curtas, não vale a pena.

## O que não faz

- **Não remete para outras páginas.** Todas as referências permanecem nesta página.
  Para referências entre páginas, existe o widget de navegação.
- **Não aninha.** Mostra exatamente um nível, não uma árvore.
- **Não cria títulos.** Apenas identifica o que já está no texto.
