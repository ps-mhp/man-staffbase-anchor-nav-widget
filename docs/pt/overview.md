# Navegação por âncoras

O widget apresenta uma lista de ligações que tu próprio atualizas. Um clique
leva-te diretamente ao título correspondente na página; um marcador vermelho indica
em que secção te encontras e acompanha a tua navegação à medida que percorres a página.

A lista não surge por si só. É no painel de configurações que define quais
são as entradas, como se chamam e em que ordem aparecem. O
widget só procura as secções quando alguém faz scroll ou clica numa entrada
— durante o carregamento da página, não faz nada em segundo plano.

## Para que serve

Páginas longas com uma estrutura clara — um modelo de automóvel com os seus equipamentos,
uma diretiva com as suas secções. Em páginas curtas, não vale a pena.

## O que não faz

- **Não identifica títulos automaticamente.** Cada entrada é criada manualmente.
  Se for adicionada uma secção à página, esta também deve constar na lista.
- **Não aninha.** A lista é plana, não é uma árvore.
