# Ankernavigation

Das Widget zeigt eine Liste von Verweisen, die du selbst pflegst. Ein Klick
springt zur passenden Überschrift auf der Seite; eine rote Marke zeigt, welcher
Eintrag zuletzt angeklickt wurde.

Die Liste entsteht nicht von selbst. Du legst im Einstellungsdialog fest, welche
Einträge es gibt, wie sie heißen und in welcher Reihenfolge sie stehen. Das
Widget durchsucht die Seite erst, wenn jemand einen Eintrag anklickt — beim
Laden der Seite tut es nichts im Hintergrund.

## Wofür es gedacht ist

Lange Seiten mit klarer Gliederung — ein Fahrzeugmodell mit seinen Ausstattungen,
eine Richtlinie mit ihren Abschnitten. Auf kurzen Seiten lohnt es nicht.

## Was es nicht tut

- **Keine Überschriften von selbst finden.** Jeder Eintrag wird von Hand angelegt.
  Kommt auf der Seite ein Abschnitt dazu, gehört er auch in die Liste.
- **Nicht mitlaufen.** Die Marke folgt nicht dem Scrollen, sondern bleibt beim
  zuletzt angeklickten Eintrag.
- **Nicht verschachteln.** Die Liste ist flach, kein Baum.
