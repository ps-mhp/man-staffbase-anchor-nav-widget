# Navegación por encabezados

El widget lee los encabezados de la página y muestra los de un mismo nivel —H1 a
H6— como una lista de enlaces. Al hacer clic, se salta a ese punto; mientras se lee,
un marcador rojo se desplaza hasta el encabezado en el que se encuentra el usuario.

La lista se genera al cargar la página. No hay que mantenerla: si se
renombra, se desplaza o se elimina un encabezado, se modifica la navegación.

## Para qué sirve

Páginas largas con una estructura clara: un modelo de vehículo con sus equipamientos,
una directiva con sus apartados. En páginas cortas no merece la pena.

## Lo que no hace

- **No enlaza a otras páginas.** Todos los enlaces se limitan a esta página.
  Para enlaces entre páginas, existe el widget de navegación.
- **No anida elementos.** Muestra exactamente un nivel, no un árbol.
- **No crea títulos.** Solo detecta lo que ya aparece en el texto.
